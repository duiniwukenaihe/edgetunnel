# 美国子区域交付与验证

本次改造为六国家增加美国东部、中部、西部三个入口，默认共九个入口。不是聚合外部订阅，也没有新增 Cloudflare 项目、Token 或依赖。

## 本轮状态

后端与控制台已完成，并分别通过独立审查。最终生成版本通过 108 个 Node 回归、15 个 Python 测试和 11 项原生 workerd/TLS 检查。复用现有 Chrome 检查了桌面三列与窄屏单列显示；使用明确标注的本地测试数据，不代表线上可用性。

上线尚未执行；Cloudflare 子区域可用性、真实客户端导入/切换与 ChatGPT 登录均为 NOT_RUN。旧国家级云端验收不能证明这版新增子区域可用。

## 发布后验证

1. 由用户授权发布到现有 naiops-us-github；访问正式域名 `/healthz` 对照发布清单的提交 SHA。旧预览地址不会随新版本自动更新。
2. 登录 `/admin/regions`，检查九个默认入口；缺少候选、过期、定位不明须分别说明。国家配置删除美国后，美国子入口也应消失。
3. 刷新美国自动，检查实际出口的 country/regionCode/city、检测时间及国家池发现/探测数量。三子区域复用共享池，不应该各发一轮重复检测。每轮限 4、并发 2，刷新至少间隔 60 秒。
4. 复制 VLESS 订阅给 v2rayA，应有九个地区入口；Mihomo 应有九个地区组、十八条协议节点。仅美国东部订阅应只有该入口；全部订阅美国自动排第一。
5. 在实际走该代理的客户端检查 Cloudflare trace 的 `loc=US` 和 IP。trace 只证明观测国家；美国子区域要对照同一实际出口 IP 的州信息及分区规则。重新连接可能换 IP，旧记录不证明新连接。
6. 验证所选子区域的真实主备切换。没有新鲜匹配州证据时关闭连接，不能转到另一个美国子区或直接连接；国家自动允许所有已验证美国州及未知州。
7. ChatGPT 账号登录单独实际验证，国家证明、连通性或延迟不保证账号登录。

## 自动更新与限制

自动来源仍是六国家的固定动态 DNS。发现上限每国家 32、每轮探测 4，并非全网扫描或已获取 100 个节点。池分批轮询，候选的位置/信誉/可用性会变化。15 分钟更新为认证请求触发，空闲时暂停，单条证据最长 30 分钟。

地理分类依据出口回到本项目时 Cloudflare 对来访 IP 的地理信息，是 IP 定位而非物理位置保证；缺失州代码不会填造城市或子区域。分区规则详见 README。

## 证据与撤销

每次候选拨号同步检查当前实例的最新撤销权限；单个探测发现州变化或无效回执时立即撤销，不等待同批其他探测结束。临时网络超时不会延长旧证据的有效期。保存失败时，当前实例独立保留撤销记录，最多 256 项；达到保护上限失败关闭。跨实例/跨机房的 KV 传播仍受平台一致性约束，不宣称全局原子撤销。
