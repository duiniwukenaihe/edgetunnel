# 自动出口实现与验收

日期：2026-10-09。实现目标：默认美国，动态候选、实测国家、同区域主备、过期关闭，保留现有项目与手动发布流程。

## 代码与回归

- 新增 `policy/auto-exits.js`，通过受守卫的生成器嵌入上游；未改原始上游快照及版本锁。
- 固定美国 DoH 来源、公共 IP:443 校验、响应大小与请求预算；每轮最多 4 候选、并发 2、单候选 4 秒、整体 12 秒。
- 检测缓存按版本、域名、边缘、区域与配置隔离；请求驱动 15 分钟刷新、30 分钟过期、失败后 60 秒退避。临时故障不延长旧证据，明确国家变化立即剔除。
- 真实 WS/VLESS、WS/SS、XHTTP、gRPC 解析器的错误凭据均不触发出口检测；匿名刷新和无 token 的上游 BEST_SUB 请求也不触发。
- 每次实际 TCP 拨号或重试检查有效池；没有有效池不拨手动地址、直连目标或其他区域。旧连接不主动热切换。
- 面板新增自动发现、当前边缘状态和刷新。已有版本 1 配置保留手动模式，保存为版本 2；不改变 ADMIN、HOST、UUID 和旧 config.json。
- 独立审查发现并实际复现了国家变化后旧结果残留、上下文/重试绕过过期、普通 TLS 断线被当证书证据、Socket Promise 未处理、刷新错误详情丢失。分别新增失败回归并修正。另补充国家变化与 KV 写入失败的组合回归：明确失效的实例内结果先撤销，不因保存失败恢复。另验证取消信号被忽略时 12 秒硬截止时间仍返回失败，晚到结果不入池。
- 完整验证：15 项 Python、66 项 Node、生成来源一致性、模块及内联页面脚本语法。代理/缓存单元测试使用显式网络夹具，不证明真实免费出口可用。

## 原生运行时证据与阻碍

使用 `tests/native-tls-runtime.cjs` 调用生产检测代码。测试只在 Socket 边界将目标映射到本地 CA 受控 TLS 服务，增加该 CA 到测试运行时；生产代码不增加证书信任或禁用校验。

| 检查 | 结果 |
| --- | --- |
| 正确证书、正确域名，读取 HTTP 200 US trace | 通过 |
| 错误域名 | 拒绝，但仅返回 Network connection lost |
| 不可信证书 | 拒绝，但仅返回 Network connection lost |
| 完整候选入池 | 拒绝：普通断线不能算明确的证书域名拒绝证据 |
| 测试进程、临时证书目录回收 | 已完成 |

因此报告为 `safetyTestsPassed=true`、`runtimeReady=false`。这是安全失败测试通过，不是节点验收通过。证书域名拒绝只能接受明确的错误码或信息；不得将 reset、EOF 或超时作为证书证明。Cloudflare 的 [相关未关闭问题](https://github.com/cloudflare/workerd/issues/6903) 也描述本地与云端 expectedServerHostname 行为差异；该问题记录不替代我们自己的云端测试。
