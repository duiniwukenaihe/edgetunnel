# 与上游的差异

比较基线为 [cmliu/edgetunnel 的 a8ab11125ece](https://github.com/cmliu/edgetunnel/commit/a8ab11125ece9bc27983f609a6359be81b21050c)，对应 [upstream/version.json](../upstream/version.json)。2026-10-09 查询上游 main，仍为该提交。后续以版本锁为实际导入基线；同步不保证兼容任意未来上游版本。

[GitHub 完整差异](https://github.com/duiniwukenaihe/edgetunnel/compare/a8ab11125ece9bc27983f609a6359be81b21050c...main)包含生成源码、维护脚本、工作流、测试和本分支文档。当前原始 worker 快照与锁定上游逐字节一致；它用于可重现生成，所以快照的大量新增行不代表重写了整份业务代码。

## 运行代码改动

| 改动位置 | 原来的行为 | 现在的行为 | 目的 |
| --- | --- | --- | --- |
| fetch 入口 | ADMIN 可由多个变量别名、KEY 或 UUID 代替 | 仅 ADMIN 可作为管理密码，缺失先返回 503 | 防止只设置节点标识就启用服务 |
| /healthz | 无此定制接口 | 检查 ADMIN、KV，返回状态和发布 SHA；不包含凭据 | 判断环境绑定与上线版本 |
| 创建请求TCP连接器 | request.fetcher.connect | cloudflare:sockets.connect | 使用 Pages/Workers 标准 TCP API |
| 反代参数获取 | 接受路径、查询、默认反代和链式代理设置 | 全局固定美国候选，关闭直连兜底，禁止这些设置覆盖 | 保持本分支的出口边界 |
| 解析地址端口 | 按域名和标识散列排序 | 保留候选原顺序 | ChatGPT 和相关登录域名使用同一主备顺序 |
| 反代并发拨号数 | 可由环境变量调整 | 固定为 1 | 主候选失败后才尝试备用 |
| /sub | 生成多种格式、调用外部转换器等 | 仅原生 Clash/mixed；mixed 仅输出 VLESS/SS，其余返回 400 | 避免转换器与导入节点改变交付范围 |
| Clash 生成 | 通用转换生成 | 本地生成 VLESS、SS、fallback 和 MATCH 规则 | 提供明确的协议切换配置 |
| 通用 SS 链接 | 上游订阅路径 | SIP002 用户信息含真实节点密码、v2ray-plugin 参数 | 可被支持该插件的客户端导入 |

定制逻辑由 [生成脚本](../scripts/apply-us-policy.py)和[策略文件](../policy/us-only.js)应用到原始 worker，再生成 [_worker.js](../_worker.js)。不直接手工维护完整 worker 的副本。

上游其他协议和面板实现大部分仍保留。本分支没有将全部 Trojan 实现删除；其原生订阅交付范围和已实测范围为 VLESS/SS。原面板的一些设置仍能保存，但不会覆盖固定反代策略或原生订阅格式限制。

## 自动更新与发布改动

- 保存原始 worker 快照和提交/hash 锁；获取上游新提交后重应用本仓库策略。许可证发生变化时停止。
- 生成锚点必须唯一且匹配；上游结构不兼容时停止，不静默生成不确定的代码。
- 新增 CI：生成一致性、模块语法、11 项 Python 流程测试、17 项 Node 回归测试。
- 替换原同步方式：先验证当前 main，再生成和测试候选，通过后无强推地原子更新 upstream-candidate 与 main；遇到并发变更停止。
- 同步只更新三个源码/来源文件，不自动覆盖本分支 README、工作流或依赖。
- 新增固定提交发布准备：部署包含版本戳，附带 worker SHA256；构建拒绝与检出 HEAD 不同的提交，产物放在仓库之外。
- cloudflare-production 环境只允许 main，审核人为 duiniwukenaihe，禁止管理员跳过；Token 放在保护环境，普通测试和打包不读取它。
- GitHub 发布目标改为 naiops-us-github；上线检查必须 ready 且返回被批准的准确提交，使用明确的检查客户端名称以避免实测默认客户端 1010 拒绝。
- 发布开关目前 false；这次已授权的实际部署使用已有 Wrangler 授权完成，GitHub 后续 deploy 尚待配置 Token 并启用。工作流存在不等于 GitHub 已实际执行生产发布。

完整操作见[自动同步与授权发布](自动同步与授权发布.md)。

## GitHub 修改与云端配置的区别

ADMIN、HOST、KV 绑定、fail_open 和域名迁移是 Cloudflare 项目设置，不是 GitHub 源码中的密码或状态。密码、真实节点 UUID、token、完整私密订阅地址没有提交到仓库。

当前云端项目 naiops-us-github 绑定服务域名 us.naiops.ccwu.cc。旧项目保留且原生 Git 自动构建暂停。仓库中的 wrangler.toml 沿用上游模板，不是当前 Pages 项目的实际绑定配置；生产发布目标由 deploy.yml 明确指定。

## 已证明与未证明

2026-10-09 的真实 VLESS 和 SS 测试均验证 TLS、HTTP 200、美国主出口 3.132.174.45。备用 192.3.208.192 的独立候选检查也为 US，但不等于部署后的真实故障切换。

回归测试证明候选顺序、主失败尝试备用、全失败关闭、不走直连、认证边界、订阅内容和准确发布版本。真实人为出口故障与客户端切换未测试；ChatGPT 程序探测返回 403，账号登录没有验收。

Mihomo 的 fallback 检测配置为 Cloudflare trace、HTTP 200、每 300 秒检查；该地址经真实线路验证可达。它检测连通性，不解析响应中的国家，也不会证明 ChatGPT 的账号登录状态。服务端切换由 TCP 拨号失败触发，不根据 HTTP 403 或延迟自动全网优选。

固定候选不保证未来一直在美国、在线或适合 ChatGPT。修改候选前需实测，再通过测试、审批和上线验收。
