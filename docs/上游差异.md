# 与上游的差异

比较基线由 [upstream/version.json](../upstream/version.json) 确定，当前导入 [cmliu/edgetunnel 的 a8ab11125ece](https://github.com/cmliu/edgetunnel/commit/a8ab11125ece9bc27983f609a6359be81b21050c)。[完整 GitHub 差异](https://github.com/duiniwukenaihe/edgetunnel/compare/a8ab11125ece9bc27983f609a6359be81b21050c...main)含原始源码快照、维护工具、生成源码与文档；快照用于重现，新增行数不表示业务重写。

| 位置 | 上游行为 | 本分支行为 |
| --- | --- | --- |
| 管理密码 | 多变量别名、KEY/UUID 可代替 ADMIN | 只允许 ADMIN，缺失返回 503 |
| TCP 连接 | request.fetcher.connect | 标准 cloudflare:sockets.connect |
| 出口配置 | 路径/查询 ProxyIP、默认环境反代、链式代理等 | 面板维护区域与自动/手动候选；默认 US，认证后仅使用实际 loc 与证书验证通过的有效池 |
| UDP/DNS 隧道 | DNS 直连公共解析器 | 拒绝 UDP，避免绕过地区池；订阅声明 udp=false |
| 主备与兜底 | 散列排序、并发与可选兜底 | 保留健康主出口，拨号并发 1，失效关闭，不跨区、不直连 |
| 自动发现/检测 | 按入口机房默认反代域名、随机入口 CIDR、外部优选来源 | 固定美国 DNS 来源 + 手动公共 IP:443；实测国家与证书，15 分钟请求驱动刷新、30 分钟过期 |
| 管理页 | 外部上游页面 | 新增自托管区域页与认证读写接口，旧页保留 /admin/settings |
| KV 配置 | 原有 config.json 等 | 独立 regions.json v2（v1 读取保留手动）；检测缓存按版本/域名/边缘/地区/配置隔离，损坏拒绝 |
| 订阅 | 多格式及外部转换器 | 原生 Clash/mixed；VLESS/SS 区域路径明确，不请求转换器 |
| Mihomo | 通用转换 | 默认优先地区选择、每区协议 fallback、真实检测地址、无 DIRECT |
| /healthz | 无定制接口 | ADMIN/KV 状态及准确发布 SHA，不包含凭据 |
| 上游同步 | 原同步流程 | 明确上游 SHA、重应用策略、回归后原子更新 main |
| 发布 | Git 构建或上传 | 仅手动生成固定 SHA 发布包；默认用户上传当前项目，可选审批 Token 上传 |

策略来源为 [policy/regions.js](../policy/regions.js)、[policy/auto-exits.js](../policy/auto-exits.js)、[policy/regions.html](../policy/regions.html)，由 [scripts/apply-us-policy.py](../scripts/apply-us-policy.py) 合入上游生成 [_worker.js](../_worker.js)。生成入口沿用历史名称，不代表只支持美国。修改生成文件而未修改策略会被一致性校验拒绝。

上游其他协议实现大部分仍保留，原生订阅交付为 VLESS/SS。旧面板反代设置、PROXYIP 环境变量和任意 URL IP 无法覆盖区域池。每个代理请求和原生订阅使用局部区域配置，不共享地区选择。

## 发布与云端配置

现有 naiops-us-github 采用直接上传，服务域名为 us.naiops.ccwu.cc；保留项目、ADMIN、HOST、KV 与 fail_open=false。旧项目 naiops-us 保留，原生 Git 自动构建已暂停；旧平台限制原因仍未由 Cloudflare 说明。仓库 wrangler.toml 是沿用的上游模板，不代表当前 Pages 绑定；可选自动发布目标明确写在 deploy.yml。

GitHub 仅手动触发 Prepare release (manual)。测试、固定提交打包不使用 Cloudflare 密钥；默认 deploy skipped，用户下载内部部署 ZIP 并在当前项目点击 Save and Deploy。可选自动上传需要专用 Token 和每次所有者审批，但本轮不配置或启用。main 日常同步不触发发布。

真实 ADMIN、节点 UUID、Token 和私密订阅地址不提交仓库。区域出口及标签是运行设置，KV 不是 GitHub 发布凭据的存放位置。

## 验证边界

回归覆盖默认区域、数据校验/保存/认证、存储故障、未知地区、并发上下文、区域主备及全失败、VLESS/SS/Mihomo 地区一致性、生成来源、固定发布 SHA 与审批边界。此前区域页做过本地浏览器验证；本次新增自动出口 UI 尚未浏览器验收。实际云端检测门槛未通过，因此不发布。

2026-10-09 线上固定美国版本真实 VLESS/SS 曾实测 TLS、HTTP 200、主出口 3.132.174.45 与 US；备用独立检测为 US，但不等于真实客户端故障切换。此次自动出口代码尚未在 Cloudflare 发布，详见[验收记录](自动出口验收.md)。ChatGPT 无登录探测曾返回 403，账号登录未验收。

保存地区配置不等于启用候选。新 TCP 拨号与重试只使用未过期的实际国家及证书检查结果；明确国家变化立即剔除，暂时网络故障不延长旧结果。Mihomo 检测连通性，不解析国家，不证明账号登录。服务器保留健康主出口，HTTP 403 不触发换 IP。免费出口国家、信誉和可用性可能改变。
