# Automatic US exit pool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking. Execute inline in the clean task branch; an independent code reviewer is required before merge.

**Goal:** Discover and verify US exits automatically, retain a healthy primary and fail closed on expired/unknown exits.

**Architecture:** Independent policy source files embed into the preserved upstream worker. Native certificate-verified TLS probes feed a per-origin/colo/config KV cache; only authenticated requests trigger discovery. Existing regional subscriptions retain stable paths.

**Tech Stack:** Existing Python generator, JavaScript, Workers sockets/native TLS, KV, Node built-in tests; no new dependency.

## Global Constraints

- Existing project/domain/ADMIN/KV; no new project or GitHub Cloudflare Secret.
- Refresh 15 minutes, expiry 30 minutes, 4 probes, concurrency 2, 4-second candidate and 12-second refresh timeouts, 32 discovery candidates and at most 8 active exits.
- Country must match selected region. No direct/cross-region fallback; preserve healthy primary.
- Low disk: cached tools only, one runtime process, temporary output outside Git, cleanup at finish.
