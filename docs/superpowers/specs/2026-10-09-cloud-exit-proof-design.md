# 云端出口检测修复

用户已要求先修好云端检测，再补多地区自动来源并验收；拒绝手工维护候选。

原检测依赖生产运行时无法可靠支持的 IP 连接 + expectedServerHostname。上游 TlsClient 不验证证书链及 CertificateVerify，不能直接把其握手成功当作国家信息认证。

选择本项目签名回执方案：候选连接固定当前项目 hostname 的公开 GET /__naiops_exit_probe，携带每次新生成的 128 bit nonce。接收端只使用 Cloudflare 的 country 和 CF-Connecting-IP 元数据，返回 nonce、hostname、发布 SHA、时间、出口 IP、国家及 HMAC-SHA256 签名。密钥独立随机生成 32 字节，保存在现有 KV 的 __naiops_exit_receipt_key_v1，绝不发给候选或客户端，不依赖 ADMIN 熵。部署时用既有 Cloudflare 授权由单一步骤预置一次随机值，存在时复用且不覆盖；公开接口和运行时检测都只读取，不在线读空再写，避免 KV 负缓存与跨实例竞争。接口没有外部 URL、登录授权或代理能力。拒绝 CF-Worker 和规范化的 2a06:98c0:3600::103 特殊地址，只使用 Cloudflare 原生 IP 元数据。

探测传输复用上游 TLS 代码发送正确 SNI，但不将该传输宣称为证书验证。随机检测值没有秘密；签名而非未经验证的证书认证回执。验证严格绑定 nonce、域名、版本，拒绝超过 10 秒或超前 2 秒的响应、错误签名及国家；只把 proofVerified=true 记录持久化启用。旧 tlsNameVerified 缓存不得视为新验证。客户端真实目标 TLS 仍由客户端验证。

保留公共 IP:443 限制、最多四个候选/并发二/12 秒检测期限、15 分钟更新/30 分钟过期、区内主备、禁止直连/跨区和 ADMIN 管理权限。公开回执接口只支持合法一次性值的 GET，缺少有效边缘元数据则失败，不泄露配置和凭据。该机制证明检测时访问本项目的出口，不证明每个未来目标始终同一国家。

先验证签名负例、生命周期以及真实 TLS 受控服务，再在同一 Pages 项目预览验证美国和真实 VLESS/SS；云端检测成功之前不扩大地区、不发布生产。后续多地区独立步骤将预置目录与实际可用状态区分，自动来源由程序维护，不让用户填 IP。
